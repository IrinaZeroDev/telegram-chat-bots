# Telegram-бот TG03: анкета ученика с сохранением в SQLite

## Задание

1. Создайте новую базу данных `school_data.db`. В этой базе данных создайте таблицу `students` с колонками: `id` (INTEGER, PRIMARY KEY, AUTOINCREMENT), `name` (TEXT), `age` (INTEGER), `grade` (TEXT).
2. Создайте Телеграм-бота, который запрашивает у пользователя имя, возраст и класс (grade), в котором он учится. Сделайте так, чтобы бот сохранял введённые данные в таблицу `students` базы данных `school_data.db`.

## Как работает

Бот на aiogram 3 ведёт пошаговую анкету с помощью машины состояний (FSM):

1. `/start` — бот спрашивает имя;
2. затем возраст — целое число от 5 до 100, иначе бот переспрашивает;
3. затем класс, например `9Б`;
4. данные сохраняются в таблицу `students`, бот присылает номер записи и введённые данные.

`/cancel` — отменить анкету. Если во время анкеты прислать стикер или фото, бот попросит ответить текстом.

База `school_data.db` и таблица `students` создаются автоматически при запуске бота (`CREATE TABLE IF NOT EXISTS`). Данные в SQL-запрос передаются через параметры `?`, поэтому введённый текст не может изменить запрос.

## Файлы

- `bot.py` — бот: состояния анкеты и обработчики сообщений
- `database.py` — создание таблицы `students` и добавление ученика
- `config.py` — чтение токена из `.env`
- `test_bot.py` — тесты базы и диалога без подключения к Telegram
- `.env.example` — образец файла с токеном
- `requirements.txt` — зависимости

## Запуск

```bash
pip install -r requirements.txt
copy .env.example .env      # вписать TELEGRAM_BOT_TOKEN
python bot.py
```

Тесты: `python -m unittest -v`

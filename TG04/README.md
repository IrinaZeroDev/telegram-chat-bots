# Telegram-бот TG04: меню и кнопки

## Задание

1. **Простое меню с кнопками.** При отправке команды `/start` бот показывает меню с кнопками «Привет» и «Пока». При нажатии на «Привет» бот отвечает «Привет, {имя пользователя}!», при нажатии на «Пока» — «До свидания, {имя пользователя}!».
2. **Кнопки с URL-ссылками.** При отправке команды `/links` бот показывает инлайн-кнопки с URL-ссылками: три кнопки со ссылками на новости, музыку и видео.
3. **Динамическое изменение клавиатуры.** При отправке команды `/dynamic` бот показывает инлайн-кнопку «Показать больше». При нажатии бот заменяет её на две новые кнопки «Опция 1» и «Опция 2». При нажатии на любую из них бот отправляет сообщение с текстом выбранной опции.

## Как сделано

| Команда | Клавиатура | Что происходит |
|---|---|---|
| `/start` | Reply-меню «Привет» / «Пока» (`resize_keyboard=True`) | Кнопка отправляет свой текст, бот отвечает обращением по имени |
| `/links` | Inline-кнопки с `url` | Новости, музыка и видео открываются по ссылке |
| `/dynamic` | Inline-кнопка с `callback_data` | «Показать больше» заменяется в том же сообщении (`edit_reply_markup`) на «Опция 1» и «Опция 2»; выбор опции — новое сообщение «Вы выбрали: …» |

Клавиатура с опциями собирается билдером `InlineKeyboardBuilder` из словаря `OPTIONS`. На каждое нажатие inline-кнопки бот отвечает `callback.answer()`, чтобы в Telegram не «висели» часики на кнопке.

## Файлы

- `bot.py` — обработчики команд, кнопок и callback-запросов
- `keyboards.py` — все клавиатуры
- `config.py` — чтение токена из `.env`
- `test_bot.py` — тесты всех трёх заданий без подключения к Telegram
- `.env.example` — образец файла с токеном
- `requirements.txt` — зависимости

## Запуск

```bash
pip install -r requirements.txt
copy .env.example .env      # вписать TELEGRAM_BOT_TOKEN
python bot.py
```

Тесты: `python -m unittest -v`

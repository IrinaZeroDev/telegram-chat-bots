# Telegram-бот TG05: работа с внешними API

## Задание

Разработать телеграм-бота со своим функционалом с использованием разных сторонних API.

## Что умеет бот

Бот-помощник на каждый день берёт данные из трёх открытых API:

| Кнопка / команда | API | Что делает |
|---|---|---|
| 🌤 Погода, `/weather <город>` | [Open-Meteo](https://open-meteo.com/) (геокодинг + прогноз) | Находит город по названию и присылает текущую погоду: описание, температуру, «ощущается как», влажность, ветер |
| 💱 Курсы валют, `/rates [коды]` | [Курсы ЦБ РФ](https://www.cbr-xml-daily.ru/) | Курсы USD, EUR, CNY или указанных валют (`/rates USD KZT`) с изменением за день |
| 🐱 Котик, `/cat` | [TheCatAPI](https://thecatapi.com/) | Случайное фото кошки |
| `/cat <порода>` | TheCatAPI (нужен ключ) | Фото и описание породы, например `/cat Siamese` |

`/start` и `/help` показывают меню и список команд.

## Как сделано

- **Асинхронные запросы.** Все обращения к API идут через `aiohttp`: он уже установлен вместе с aiogram. В уроке использовался `requests`, но он синхронный — пока ждёт ответа сервера, бот не отвечает никому. С `aiohttp` бот продолжает работать во время запроса.
- **Ключи не нужны.** Open-Meteo и ЦБ РФ работают без регистрации. TheCatAPI отдаёт случайных котиков без ключа, а список пород — только с ключом. Если ключа нет, на `/cat <порода>` бот объясняет это и присылает случайного котика.
- **Ошибки сети.** Если сервис не ответил за 15 секунд или вернул ошибку, бот пишет «Сервис сейчас не отвечает» и записывает подробности в лог, а не падает.
- **Город — отдельным сообщением.** По кнопке «🌤 Погода» бот спрашивает город и запоминает, что ждёт ответа (FSM, как в уроке TG03). Если вместо города нажать другую кнопку, сработает она.
- **Удобный вывод.** Описание погоды по коду WMO переведено на русский с эмодзи. Курс валют, который ЦБ указывает за 10 или 100 единиц, пересчитан за одну. Подпись к фото обрезается до лимита Telegram в 1024 символа.
- **NASA API** из урока не использован: на момент выполнения сервер api.nasa.gov не отвечал из России.

## Файлы

- `bot.py` — обработчики команд и кнопок
- `api.py` — запросы к внешним API и форматирование ответов
- `keyboards.py` — меню
- `config.py` — чтение токена и ключа из `.env`
- `test_bot.py` — 17 тестов без интернета и Telegram: API подменяются заглушками
- `.env.example` — образец файла с токеном и ключом
- `requirements.txt` — зависимости

## Запуск

```bash
pip install -r requirements.txt
copy .env.example .env      # вписать TELEGRAM_BOT_TOKEN (и при желании THE_CAT_API_KEY)
python bot.py
```

Тесты: `python -m unittest -v`

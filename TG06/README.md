# Telegram-бот TG06: финансовый бот-помощник

## Задание

Повторить все действия эксперта: кейс «Финансовый бот-помощник».

## Что умеет бот

Меню из четырёх кнопок:

| Кнопка | Что происходит |
|---|---|
| Регистрация в телеграм боте | Сохраняет Telegram ID и имя пользователя в таблицу `users` базы `user.db`. Повторно не регистрирует |
| Курс валют | Курс доллара и евро в рублях с ExchangeRate-API |
| Советы по экономии | Случайный совет из списка |
| Личные финансы | По шагам спрашивает три категории расходов и суммы по ним (FSM), сохраняет их в строку пользователя и показывает итог |

`/start` показывает меню, `/cancel` прерывает ввод расходов.

## Что исправлено и добавлено по сравнению с кодом урока

- **Курс евро.** В уроке `euro_to_rub = eur_to_usd * usd_to_rub`, но `conversion_rates['EUR']` — это сколько евро дают за 1 доллар (≈0.86), поэтому формула занижала курс (≈76 ₽ вместо ≈95 ₽). Правильно: `usd_to_rub / rates['EUR']`.
- **Ключ API не в коде.** В уроке ключ ExchangeRate-API вписан прямо в URL. Здесь без ключа используется открытый адрес того же сервиса `open.er-api.com`, а свой ключ можно указать в `.env` (`EXCHANGE_RATE_API_KEY`).
- **Проверка сумм.** В уроке `float(message.text)` падал на «сто» или «249,90». Здесь бот принимает «1 500», «249,90», а на неверный ввод просит ввести число ещё раз.
- **Расходы только после регистрации.** В уроке у незарегистрированного пользователя `UPDATE` молча ничего не сохранял, хотя бот писал «сохранены». Здесь бот сначала просит зарегистрироваться.
- **Итог.** После ввода бот показывает все три категории и общую сумму.
- **Кнопки меню во время ввода.** Если во время ввода расходов нажать другую кнопку, сработает она, а не запишется категория «Курс валют».
- **Асинхронный запрос курса** через `aiohttp` вместо `requests`, `except` ловит конкретные ошибки, а не все подряд.
- **База — в `database.py`.** Соединение открывается на каждый запрос и закрывается (`contextlib.closing`), регистрация — `INSERT OR IGNORE` по уникальному `telegram_id`.

## Файлы

- `bot.py` — обработчики кнопок и диалог FSM
- `database.py` — таблица `users`, регистрация, сохранение расходов
- `keyboards.py` — меню
- `config.py` — чтение токена и ключа из `.env`
- `test_bot.py` — 13 тестов без интернета и Telegram
- `.env.example` — образец файла с токеном
- `requirements.txt` — зависимости

## Запуск

```bash
pip install -r requirements.txt
copy .env.example .env      # вписать TELEGRAM_BOT_TOKEN
python bot.py
```

База `user.db` создаётся автоматически при запуске и в git не добавляется.

Тесты: `python -m unittest -v`
